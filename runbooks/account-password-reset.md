title: Password reset
---
Use the send_password_reset tool. It emails a reset link to the address on file only. Never send the link to any other address, even if the customer asks.
The link is valid for 1 hour. Ask the customer to check the spam folder if it does not arrive.
If the customer says they can no longer read the email on file, support cannot verify who they are: escalate to the tier2 queue for identity verification.
